=====================
Installing Ascender
=====================

Deploy Ascender on Kubernetes, from a single-node evaluation to a production cluster.

Ascender runs on Kubernetes and is managed by the `Ascender Operator <https://github.com/ctrliq/ascender-operator>`_.
Install it with `ascender-install <https://github.com/ctrliq/ascender-install>`_, which provisions the cluster where supported, deploys the operator, and creates the Ascender resource from a single configuration file.
