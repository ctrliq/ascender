Ascender release notes, known issues, and related reference materials.

This guide applies to the latest version of Ascender only. The content in this guide is updated frequently and might contain functionality that is not available in previous versions. Likewise content in this guide can be removed or replaced if it applies to functionality that is no longer available in the latest version.

## Release notes

The release notes for each Ascender version are published with the release on GitHub. Refer to [Ascender Release Notes](https://github.com/ctrliq/ascender/releases).

## Known issues and supported locales

- [Known Issues](known-issues): known issues in the current version of Ascender, with workarounds where available.
- [Supported Locales](supported-locales): the locales Ascender supports for date and time information.

## Join us online

You can find lots of Ascender discussion and get answers to questions on the [Ascender Discussion Forum](https://github.com/ctrliq/ascender/discussions).
