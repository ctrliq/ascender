Ascender is an automation platform for running Ansible at scale: a web user interface, a REST API, and a task engine that runs playbooks against your inventories with role-based access control, credentials kept encrypted, job templates, workflows, schedules, and Automation Mesh.

## Documentation

- [Installation](installation): install, upgrade, and uninstall Ascender with the Ascender installer.
- [Admin Guide](admin-guide): configure authentication, security, clustering, logging, backup and restore, and system settings.
- [User Guide](user-guide): day-to-day use of Ascender, from the quick start to inventories, credentials, job templates, and workflows.
- [Release Notes](release-notes): release history, known issues, and supported locales.

## Getting help

Ask questions and discuss Ascender on the [Ascender forum](https://forum.ascender-automation.org). Report bugs and request features in [Ascender's GitHub issues](https://github.com/ctrliq/ascender/issues).
