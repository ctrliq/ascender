---
title: Custom Inventory Scripts
description: Custom inventory scripts are discontinued in Ascender; migrate them to inventory sources sourced from a project.
weight: 40
---

Inventory scripts have been discontinued. For more information, see [Export old inventory scripts](/user-guide/inventories#export-old-inventory-scripts) in the [Ascender user guides](/user-guide).

If you use custom inventory scripts, migrate to sourcing these scripts from a project. See [Inventory File Importing](../inventory-file-importing), and also refer to [Inventory sources](/user-guide/inventories#inventory-sources) in the [Ascender user guides](/user-guide) for more detail.

If you are migrating to execution environments, see:

- [Upgrading to Execution Environments](../upgrade-considerations#upgrading-to-execution-environments)
- [View mesh topology](../upgrade-considerations#view-mesh-topology) in [Upgrade Considerations](../upgrade-considerations) to validate your topology

If you already have a mesh topology set up and want to view node type, node health, and specific details about each node, see [Topology Viewer](../topology-viewer).
